## 🎯 语音识别基础概念

### 什么是语音识别？
语音识别（Speech Recognition）是将人类语音转换为文本的技术，也称为自动语音识别（ASR）。

### 语音识别的工作流程
```mermaid
graph LR
    A[音频输入] --> B[预处理]
    B --> C[特征提取]
    C --> D[声学模型]
    D --> E[语言模型]
    E --> F[文本输出]
```

### 关键技术组件
1. **音频采集**：麦克风录音、文件上传
2. **信号预处理**：降噪、标准化
3. **特征提取**：MFCC、频谱分析
4. **模型推理**：深度学习模型识别
5. **后处理**：语言模型修正

## 🏗️ 技术架构选择

### 前端语音识别方案

#### 1. Web Speech API（推荐用于实时识别）
```javascript
// 浏览器原生支持，无需服务器
const recognition = new webkitSpeechRecognition();
recognition.lang = 'zh-CN';
recognition.continuous = false;
recognition.interimResults = false;
```

**优点：**
- ✅ 实时识别，延迟低
- ✅ 无需服务器资源
- ✅ 准确率较高
- ✅ 简单易用

**缺点：**
- ❌ 需要网络连接
- ❌ 浏览器兼容性限制
- ❌ 隐私考虑（数据发送到Google）

#### 2. MediaRecorder API + 服务器处理
```javascript
// 录音后上传到服务器处理
const mediaRecorder = new MediaRecorder(stream);
mediaRecorder.ondataavailable = (event) => {
    audioChunks.push(event.data);
};
```

**优点：**
- ✅ 完全控制数据隐私
- ✅ 可使用自定义模型
- ✅ 支持离线处理
- ✅ 更好的安全性

**缺点：**
- ❌ 需要服务器资源
- ❌ 延迟较高
- ❌ 实现复杂度高

```javascript
function initSpeechRecognition() {
    // 检查浏览器支持
    if ('webkitSpeechRecognition' in window || 'SpeechRecognition' in window) {
        const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
        speechRecognition = new SpeechRecognition();

        // 配置参数
        speechRecognition.continuous = false;      // 不连续识别
        speechRecognition.interimResults = false; // 不要中间结果
        speechRecognition.lang = 'zh-CN';         // 中文识别

        // 识别成功回调
        speechRecognition.onresult = function(event) {
            const transcript = event.results[0][0].transcript;
            const confidence = event.results[0][0].confidence;

            console.log('识别结果:', transcript);
            console.log('置信度:', confidence);

            // 显示结果
            resultText.textContent = transcript;

            // 发送到后端处理
            processText(transcript);
        };

        // 错误处理
        speechRecognition.onerror = function(event) {
            console.error('语音识别错误:', event.error);

            switch(event.error) {
                case 'no-speech':
                    showError('没有检测到语音，请重试');
                    // 回退到录音文件处理
                    uploadRecordedAudio();
                    break;
                case 'audio-capture':
                    showError('无法访问麦克风');
                    break;
                case 'not-allowed':
                    showError('麦克风权限被拒绝');
                    break;
                default:
                    showError('语音识别失败: ' + event.error);
            }
        };

        // 识别结束
        speechRecognition.onend = function() {
            console.log('语音识别结束');
        };

        return true;
    } else {
        console.warn('浏览器不支持语音识别');
        return false;
    }
}
```

#### 3.3 录音功能实现
```javascript
async function startRecording() {
    try {
        // 请求麦克风权限
        const stream = await navigator.mediaDevices.getUserMedia({
            audio: {
                echoCancellation: true,  // 回声消除
                noiseSuppression: true,  // 噪声抑制
                autoGainControl: true,   // 自动增益控制
                sampleRate: 44100,       // 采样率
                channelCount: 1          // 单声道
            }
        });

        // 创建录音器
        mediaRecorder = new MediaRecorder(stream, {
            mimeType: 'audio/webm'  // 使用webm格式
        });

        audioChunks = [];

        // 数据可用时收集音频数据
        mediaRecorder.ondataavailable = function(event) {
            if (event.data.size > 0) {
                audioChunks.push(event.data);
            }
        };

        // 录音停止时处理
        mediaRecorder.onstop = function() {
            // 创建音频文件
            recordedBlob = new Blob(audioChunks, { type: 'audio/webm' });

            console.log('录音完成，文件大小:', recordedBlob.size, 'bytes');

            // 停止计时器
            clearInterval(recordingTimer);

            // 显示录音信息
            showRecordingComplete();

            // 启动语音识别
            if (speechRecognition) {
                try {
                    speechRecognition.start();
                } catch (error) {
                    console.error('启动语音识别失败:', error);
                    uploadRecordedAudio(); // 回退方案
                }
            } else {
                uploadRecordedAudio(); // 回退方案
            }
        };

        // 开始录音
        mediaRecorder.start();
        recordingStartTime = Date.now();

        // 更新UI
        recordBtn.style.display = 'none';
        stopBtn.style.display = 'inline-block';
        status.style.display = 'block';

        // 启动计时器
        startRecordingTimer();

    } catch (error) {
        console.error('录音启动失败:', error);

        if (error.name === 'NotAllowedError') {
            showError('麦克风权限被拒绝，请在浏览器设置中允许访问麦克风');
        } else if (error.name === 'NotFoundError') {
            showError('未找到麦克风设备');
        } else {
            showError('无法启动录音: ' + error.message);
        }
    }
}

function stopRecording() {
    if (mediaRecorder && mediaRecorder.state !== 'inactive') {
        mediaRecorder.stop();

        // 停止所有音频轨道
        mediaRecorder.stream.getTracks().forEach(track => track.stop());
    }

    // 更新UI
    recordBtn.style.display = 'inline-block';
    stopBtn.style.display = 'none';
    status.style.display = 'none';
}

function startRecordingTimer() {
    recordingTimer = setInterval(() => {
        const elapsed = Date.now() - recordingStartTime;
        const seconds = Math.floor(elapsed / 1000);
        const minutes = Math.floor(seconds / 60);
        const displaySeconds = seconds % 60;

        timer.textContent = `${minutes.toString().padStart(2, '0')}:${displaySeconds.toString().padStart(2, '0')}`;
    }, 1000);
}
```

```javascript
async function uploadRecordedAudio() {
    if (!recordedBlob) {
        showError('没有录音文件');
        return;
    }

    // 创建文件对象
    const audioFile = new File([recordedBlob], 'recording.webm', {
        type: 'audio/webm'
    });

    console.log('上传文件:', audioFile.name, '大小:', audioFile.size, '类型:', audioFile.type);

    // 创建表单数据
    const formData = new FormData();
    formData.append('audio', audioFile);

    // 显示加载状态
    showLoading('正在处理音频...');

    try {
        const response = await fetch('/upload', {
            method: 'POST',
            body: formData
        });

        const data = await response.json();

        if (response.ok && data.success) {
            // 显示识别结果
            resultText.textContent = data.recognized_text;

            // 处理AI回答
            if (data.answer) {
                displayAIResponse(data.answer, data.intent);
            }
        } else {
            showError(data.error || '服务器处理失败');
        }
    } catch (error) {
        console.error('上传失败:', error);
        showError('网络错误，请检查服务器连接');
    } finally {
        hideLoading();
    }
```

#### 2. Whisper 模型加载

```python
def load_whisper_model():
    """加载Whisper模型（懒加载）"""
    global whisper_model
    if whisper_model is None:
        print("正在加载Whisper模型...")
        try:
            # 根据需要选择模型大小
            # tiny, base, small, medium, large
            whisper_model = whisper.load_model("base")
            print("Whisper模型加载完成")
        except Exception as e:
            print(f"Whisper模型加载失败: {e}")
            whisper_model = None
    return whisper_model

def check_file_extension(filename):
    """检查文件扩展名"""
    return '.' in filename and \
           filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS
```

#### 3. 语音识别实现
```python
def speech_to_text(audio_file_path):
    """
    语音转文字核心函数
    优先使用Whisper，失败时回退到Google语音识别
    """
    try:
        # 方法1: 使用Whisper进行识别（推荐）
        model = load_whisper_model()
        if model:
            print("使用Whisper进行语音识别...")
            result = model.transcribe(
                audio_file_path,
                language='zh',           # 指定中文
                fp16=False,             # CPU上使用FP32
                temperature=0.0,        # 确定性输出
                best_of=1,             # 最佳候选数
                beam_size=1,           # 束搜索大小
                word_timestamps=False   # 不需要词级时间戳
            )

            text = result["text"].strip()
            confidence = result.get("confidence", 0.0)

            print(f"Whisper识别结果: {text}")
            print(f"Whisper置信度: {confidence}")

            if text:
                return text

    except Exception as e:
        print(f"Whisper识别失败: {e}")

    # 方法2: 回退到Google语音识别
    try:
        print("回退到Google语音识别...")
        recognizer = sr.Recognizer()

        # 音频文件预处理
        with sr.AudioFile(audio_file_path) as source:
            # 调整环境噪声
            recognizer.adjust_for_ambient_noise(source, duration=0.5)
            audio = recognizer.record(source)

        # 进行识别
        text = recognizer.recognize_google(
            audio,
            language='zh-CN',
            show_all=False  # 只返回最佳结果
        )

        print(f"Google识别结果: {text}")
        return text

    except sr.UnknownValueError:
        return "无法识别语音内容，请确保语音清晰"
    except sr.RequestError as e:
        return f"Google语音识别服务错误: {e}"
    except Exception as e:
        return f"语音识别处理失败: {e}"
```

#### 4. 文件上传处理
```python
@app.route('/upload', methods=['POST'])
def upload_file():
    """处理音频文件上传和识别"""
    try:
        # 检查文件是否存在
        if 'audio' not in request.files:
            return jsonify({'error': '没有选择音频文件'}), 400

        file = request.files['audio']
        if file.filename == '':
            return jsonify({'error': '文件名为空'}), 400

        # 检查文件类型
        if not file or not check_file_extension(file.filename):
            return jsonify({'error': '不支持的文件格式，请使用 wav, mp3, flac, m4a, webm'}), 400

        # 安全的文件名处理
        filename = secure_filename(file.filename)
        if not filename:
            filename = 'recording.webm'

        # 保存文件
        filepath = os.path.join(app.config['UPLOAD_FOLDER'], filename)
        file.save(filepath)

        print(f"文件保存成功: {filepath}")
        print(f"文件大小: {os.path.getsize(filepath)} bytes")

        # 语音识别
        recognized_text = speech_to_text(filepath)

        # 意图识别
        intent = detect_intent(recognized_text)

        # 生成AI回答
        answer = generate_ai_response(recognized_text, intent)

        # 清理临时文件
        try:
            os.remove(filepath)
        except:
            pass

        return jsonify({
            'success': True,
            'recognized_text': recognized_text,
            'intent': intent,
            'answer': answer
        })

    except Exception as e:
        # 清理可能的临时文件
        if 'filepath' in locals() and os.path.exists(filepath):
            try:
                os.remove(filepath)
            except:
                pass

        print(f"处理请求时出错: {e}")
        return jsonify({'error': f'服务器内部错误: {str(e)}'}), 500
```

```python
def detect_intent(text):

    text = text.lower()

    intent_keywords = {
        'greeting': ['你好', '您好', 'hi', 'hello', '早上好', '下午好', '晚上好'],
        'weather': ['天气', '温度', '下雨', '晴天', '阴天', '雪'],

        'news': ['新闻', '消息', '资讯', '头条'],
        'travel': ['旅游', '景点', '旅行', '去哪', '玩']
    }

    for intent, keywords in intent_keywords.items():
        for keyword in keywords:
            if keyword in text:
                return intent

    return 'unknown'
```

### 2. 语音识别准确率低
**问题**：识别结果不准确
**解决方案**：
- 在安静环境中录音
- 说话清晰，语速适中
- 调整录音参数：
```javascript
const stream = await navigator.mediaDevices.getUserMedia({
    audio: {
        echoCancellation: true,    // 回声消除
        noiseSuppression: true,    // 噪声抑制
```

```python
import redis
import hashlib

# Redis缓存
redis_client = redis.Redis(host='localhost', port=6379, db=0)

def get_cached_result(audio_hash):
    """获取缓存的识别结果"""
    try:
        cached = redis_client.get(f"speech:{audio_hash}")
        if cached:
            return json.loads(cached)
    except:
        pass
    return None

def cache_result(audio_hash, result):
    """缓存识别结果"""
    try:
        redis_client.setex(
            f"speech:{audio_hash}",
            3600,  # 1小时过期
            json.dumps(result)
        )
    except:
        pass

def speech_to_text_cached(audio_file_path):
    # 计算文件哈希
    with open(audio_file_path, 'rb') as f:
        audio_hash = hashlib.md5(f.read()).hexdigest()

    # 检查缓存
    cached_result = get_cached_result(audio_hash)
    if cached_result:
        print("使用缓存结果")
        return cached_result

    # 进行识别
    result = speech_to_text(audio_file_path)

    # 缓存结果
    cache_result(audio_hash, result)

    return result
```
